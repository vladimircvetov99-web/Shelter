# Animal Shelter Website 🐾


## Описание
Проект представляет собой сайт приюта животных, где пользователи могут:
- изучать подробную информацию о каждом питомце
-  находить контактную информацию и местоположение

<img width="1904" height="862" alt="image" src="https://github.com/user-attachments/assets/88308e0b-6283-44ee-a10d-737c20411974" />

##  Функциональность

- Каталог животных с карточками
- Страница отдельного животного
- Раздел с информацией о приюте
- Контактная страница
- Адаптивная верстка
